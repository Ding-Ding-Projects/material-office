# Contributing

Material Office welcomes focused Windows Electron contributions that preserve the security and product contracts in [AGENTS.md](AGENTS.md).

1. Open or select an issue describing observable behavior.
2. Create original code; use LibreOffice only for office behavior/API reference.
3. Keep changes scoped and add tests plus the affected feature article.
4. Run `npm ci`, `npm test`, and `npm run dist:win` on Windows when packaging changes.
5. Run `npm test` under `landing/` for documentation-site changes.
6. Submit a pull request with exact verification evidence and screenshots for visible behavior.

Do not include secrets, private documents, generated substitute imagery, downloaded fonts, or remote runtime assets.
